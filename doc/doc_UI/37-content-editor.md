# Редактор контента (посты, статьи, медиа, истории)

> Единый редактор публикаций. Формат: **DocumentV2** без offsets/placeholders ([public-content-format.md](../01-product/public-content-format.md)). API: `POST /v1/posts`, `POST /v1/posts/drafts`, `PUT /v1/posts/drafts/{id}`, `POST /v1/posts/drafts/{id}/publish`; edit опубликованного поста — `POST /v1/posts/{id}/revisions` ([rest-api.md](../05-api/rest-api.md)).

## Режимы

| Режим | Откуда открывается | kind | Особенности |
|-------|--------------------|------|-------------|
| Пост канала | [06-channel](./06-channel.md) [+ Пост] | text | Короткий текст + медиа-карусель → [32-channel-editor](./32-channel-editor.md) |
| Статья | Канал → [+ Пост] → «Статья» | article | Заголовок, форматирование, медиа в тексте → [32-channel-editor](./32-channel-editor.md) |
| Медиа-пост | Окно 3 [+], окно 5 | photo/video | Медиа первично, подпись + атрибуты → [33-media-editor](./33-media-editor.md) |
| История | Окно 4 [+ История] | — | Медиа + TTL 24ч + аудитория ([11-stories](./11-stories.md)) |

От чьего имени: пользователь / канал (роль owner/admin/author) / виртуальный пользователь (`acting_as`, [virtual-user.md](../01-product/social-objects/virtual-user.md)) — выбор при открытии, если контекстов несколько.

::: row
[**B**] [*I*] [U] [~~S~~] [`код`] [❝ цитата] [H заголовок] [• список] [🔗 ссылка] [@ упоминание] [# атрибут]
:::

::: row
[📷 Медиа] [🖼 В текст] [👁 Предпросмотр] [🕓 Отложить]
:::

> Панель форматирования создаёт текстовые узлы и node-index `markup`: entities (`bold`, `italic`, `underline`, `strikethrough`, `code`, `text_link`, `text_mention`, `hashtag`) и layout-блоки (`quote`, `heading`, `list`, `list_item`).
> Редактор формирует обязательный public `metadata` (`format_version=2`, `revision_number`, `content_mode=public`). `nodes` и `markup` опциональны и при отсутствии опускаются, а не сериализуются как `[]`/`{}`; encrypted-поля и private `secret_ref` запрещены.
> **[# атрибут]** — атрибуты поста (= хэштеги, единый реестр): автодополнение; нет совпадений → создание нового с предложением жанра ([34-attributes-genres](./34-attributes-genres.md)). Hashtag-node резолвится в тот же реестр.
> **[📷 Медиа]** — карусель вложений поста (до 10, [19-attachments-media](./19-attachments-media.md)); **[🖼 В текст]** (только статья) — media-node в позицию курсора.
> **[🕓 Отложить]** → выбор даты/времени → `scheduled_at` (пост со статусом scheduled, виден автору в списке «Отложенные»).

## Черновики

- Автосохранение каждые 5 с локально + `PUT /v1/posts/drafts/{id}` (debounce 30 с).
- Закрытие редактора с непустым контентом → «Сохранить черновик?» [Сохранить]* [Удалить].
- Список черновиков — в точке входа режима (канал → «Черновики», окно 5).
- Черновик привязан к автору-контексту (канал / ВП / пользователь).

## Предпросмотр и публикация

::: modal
## Предпросмотр

(рендер поста как в ленте: DocumentV2 nodes, карусель, атрибуты)

[Опубликовать]* [← Редактировать]
:::

> Канал с премодерацией: автор (не admin) публикует → статус **pending**, баннер «Отправлено на модерацию»; admin видит очередь → [Одобрить]/[Отклонить] (`/v1/posts/{id}/approve|reject`).
> Редактирование опубликованного поста создаёт новую immutable revision. Клиент никогда не перезаписывает опубликованную ревизию.

## Ошибки и состояния

> **Нет сети:** публикация встаёт в offline-очередь ([sync-offline.md](../04-data/sync-offline.md) §3), черновик сохранён локально.
> **Медиа не загрузилось:** пост не публикуется, ошибка на карточке вложения [Повторить].
> **Нет содержимого:** публикация недоступна без непустого текста или готового реального media/content binding. Media-only опускает `nodes`; пустой layout не считается контентом.
> **Права отозваны** (роль author снята во время редактирования): предупреждение, контент остаётся черновиком.

## Права

| Кто | Что может |
|-----|-----------|
| owner/admin канала | Посты и статьи, публикация мгновенно, модерация очереди |
| author канала | Посты и статьи; при премодерации → pending |
| Пользователь | Медиа-посты, истории, посты на свою страницу |
| Виртуальный пользователь | То же от имени ВП (`acting_as`; действует владелец/оператор, [29](./29-blogger-media-window.md)/[30](./30-blogger-news-window.md)) |
| Временный аккаунт | Только личный контент; публикации в каналы — после апгрейда |

## Адаптация

> **Телефон:** полноэкранный редактор. **Планшет/десктоп:** модал ~700px; статья — двухпанельный режим (редактор | живой предпросмотр).
