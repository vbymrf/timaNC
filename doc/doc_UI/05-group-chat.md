# Групповой чат

> **Типы:** личная группа (E2E) / публичная группа (без E2E). **Упоминания:** @username. **Родитель:** опционально сообщество ([social-objects/group.md](../01-product/social-objects/group.md)); подписка на сообщество не даёт автоматический доступ в private group.
> **Контент/API:** обязательный `metadata.content_mode` совпадает с `groups.kind`. Private допускает опциональные `encrypted_nodes`, открытый `markup`, единый `encrypted_metadata` и `secret_ref`; public — опциональные plaintext `nodes`/`markup` и `text_link`, без encrypted-полей. Отсутствующее передаётся omitted, без `[]`/`{}`/пустого ciphertext; media-only опускает текстовый массив. Сообщения: `POST /v1/groups/{group_id}/messages`.

## Строка эмодзи + ЗОНА 4

::: row
😀 😂 👍 ❤️ …
:::

::: row
[[ :emoji: ]]
[[ Напишите сообщение... @ для упоминания ]]
[[ :image: ]]
[[ :microphone: ]]
:::

> При вводе `@` — всплывающий список участников над полем. Упомянутый — отдельный push.
> Отправка активна только при непустом тексте или готовом реальном media/content binding; пустой layout контентом не считается.

> **Без права отправки:** скрыты строка эмодзи и ЗОНА 4 (режим «только чтение»).
