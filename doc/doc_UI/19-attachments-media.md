## Голосовые сообщения

> Запись: **удержание** :microphone: или переключение после ввода текста.
> **Плеер:** 1.5x / 2x, перемотка ±10 сек.
> **Статус исходящего:** ✓ отправлено → ✓✓ прослушано (для голосовых).

### Pipeline (E2E чаты / private коллекции)

1. **Отправитель:** локальная проверка содержимого и типа → Opus/JPEG/WebP → zstd (опционально) → **Kodium SecretBox** (chunked если >10 МБ).
2. **Upload:** авторизованный `POST /v1/chats/{chat_id}/media/uploads` или `POST /v1/groups/{group_id}/media/uploads` → presigned URL на **15 минут** → MinIO (**только ciphertext**).
3. **Сообщение:** реальный media binding с `media_id` находится в открытом `markup`; URL, имя и ключ входят в опциональный единый `encrypted_metadata`, если есть чувствительные метаданные. Private-ссылки используют `secret_ref`.
4. **Получатель:** авторизованно получает новый presigned URL на 15 минут, скачивает, расшифровывает и повторно проверяет содержимое перед открытием.

> Публичные чаты: plaintext upload в отдельный bucket. См. [media-storage.md](../04-data/media-storage.md).
> Прямого transfer между отправителем и получателем нет.
> Media-only DocumentV2 опускает `nodes`/`encrypted_nodes`: пустой массив, пустой `markup` или ciphertext нулевой длины не отправляются. Вложения считаются контентом только после появления реального media binding; один пустой layout не включает отправку.

### Pipeline (публичные чаты / группы)

Авторизованный `POST /v1/groups/{group_id}/media/uploads` → presigned URL на 15 минут → MinIO plaintext → server-side проверка → статус `ready` → media entity сообщения. До успешной проверки публикация и скачивание недоступны.

## Public editor pipeline (канал / медиа-пост)

> Редакторы: [32-channel-editor.md](./32-channel-editor.md), [33-media-editor.md](./33-media-editor.md). **Не** E2E path.

1. Авторизованный `POST /v1/posts/assets` → presigned URL на 15 минут (public staging bucket)
2. Upload plaintext → server-side проверка и обработка → `media_id`, варианты `thumbnail` / `preview` / `full`
3. Draft хранит media-node с `media_id` в public DocumentV2 (`metadata.content_mode=public`); encrypted-поля запрещены
4. Publish доступен только для assets в статусе `ready`

> Создание upload всегда начинается доменным запросом чата, группы или поста. Общие media endpoints используются только для завершения уже авторизованной загрузки и выдачи presigned URL; прямого transfer API нет.
