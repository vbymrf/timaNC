## Матрица шифрования

| Тип контента | Защита (UI) | Примечание |
|--------------|-------------|------------|
| Личные чаты | Да (E2E) | Participant E2E + обязательный escrow |
| Личные группы | Да (E2E) | Sender Keys + escrow |
| Личные коллекции / заметки | Да (E2E) | Только ваши устройства или фраза-backup |
| Публичные группы, каналы | Нет | Plaintext на сервере |
| Голосовые сообщения | Да (E2E) | Kodium → MinIO |
| Звонки, аудиочаты | Нет | LiveKit SRTP |

## Честное раскрытие (disclosure)

::: card

### Защищённый чат

Сообщения **шифруются на вашем устройстве**. Участники переписки не видят plaintext друг друга на сервере.

По закону провайдер может предоставить доступ правоохранительным органам по установленной процедуре — в том числе к сообщениям, удалённым вами, до истечения срока хранения.

[Политика конфиденциальности]

:::

> Юридически это **не strict E2E**. В UI — «Защищённый чат», не «абсолютная анонимность».

## Восстановление

| Что | Как |
|-----|-----|
| Пароль аккаунта | SMS + email + recovery codes |
| E2E-история | Старое устройство → peer с согласием → optional phrase backup |
| Escrow | Только юридическая процедура; **не** для пользователя |

См. [23-auth-recovery.md](./23-auth-recovery.md).
