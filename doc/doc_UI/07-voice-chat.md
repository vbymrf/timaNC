# Аудиочат (голосовая комната)

> **Родитель:** сообщество (`community_id` **обязателен**). **Контекст:** опциональная привязка к группе или каналу для точки входа в UI. **E2E:** нет. Может стать **окном 0** при активном участии. Канон: [social-objects/00-index.md](../01-product/social-objects/00-index.md).

## Точка входа

> Из [05-group-chat.md](./05-group-chat.md) / [06-channel.md](./06-channel.md) / каталога сообщества: карточка «Аудиочат» в шапке или на странице сообщества.

## Создание / админ

::: row
[Название чата___________]
[Сообщество v]  ((или создать новое при сохранении))
[Создать]*
:::

> **Auto-create:** если сообщество не выбрано — при создании автоматически создаётся сообщество-контейнер с тем же названием (редактируемо). Создатель = owner сообщества.
> Права: кто может входить и говорить, лимит участников. **Запись:** выключена по умолчанию ([recording-policy.md](../06-realtime/recording-policy.md)); если включена политикой — только public/compliance rooms с баннером согласия.
