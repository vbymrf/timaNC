## Восстановление E2E-истории

При потере устройства защищённая переписка восстанавливается **отдельно** от пароля:

| Источник | UI |
|----------|-----|
| Старое устройство | Экспорт на доверенное устройство |
| Собеседник / участник группы | Запрос с согласия peer |
| Резервная копия (opt-in) | Секретная фраза + backup blob |

::: modal

## Секретная фраза (опционально)

::: card

### Секретная фраза

Удостоверяет личность перед собеседниками и шифрует **опциональную** резервную копию.

[ ] Включить резервную копию под фразу

[Сохранить фразу]* [Пропустить]

:::

::: alert warning
Без фразы и без старого устройства личные заметки «для себя» восстановить нельзя.
:::
